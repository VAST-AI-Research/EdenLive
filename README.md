# EdenLive

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)

> **EdenLive will be open-sourced by 2026.10.18!**

**EdenLive** is a real-time generative renderer for interactive worlds. Given a proxy or a reference video — a simplified view of layout, camera, and motion, from a coding agent, an existing engine, or recorded footage — it renders a finer video stream at 24 fps or more. A target first frame and a text prompt set the look. State and interaction stay upstream; EdenLive only renders along the reference.

It is aimed at interactive scenes such as explorable game worlds, look development for the same layout and camera, restyling existing video, and turning human footage into robot views for embodied-data augmentation.
